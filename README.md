# Wix Affiliate Website

This is a compliant Wix affiliate website template that meets Impact.com's MPUA standards.

## Features

- Proper affiliate disclosures
- All required legal pages
- Responsive design
- Clean, professional appearance

## Pages

- Homepage (`index.html`)
- Privacy Policy (`privacy.html`)
- Terms of Service (`terms.html`)
- Affiliate Disclosure (`disclosure.html`)
- Cookie Policy (`cookies.html`)

## Setup

1. Clone this repository
2. Open `index.html` in your browser
3. Customize content as needed

## Compliance Notes

- All affiliate links include `rel="nofollow sponsored"`
- Clear disclosures on all pages with affiliate content
- Honest, unbiased reviews
